# HydraCut architecture

The web/BFF layer validates strict route contracts and submits durable jobs to PostgreSQL-backed queues. Immutable GitHub repository bytes and OSV/CISA/FIRST evidence are normalized into exact snapshots. HydraDB OSS stores package/application/source relationships privately; explicit OpenCypher plus native `algo.MSpaths` produces bounded receipts. Proposed fixes are evaluated as complete replacement snapshots, then one combined final proof is committed only after digest, scope, source-universe, and strong-consistency checks pass.

Deployment target: persistent zero-cost Linux VM with private PostgreSQL/HydraDB and only the web proxy public. Local Docker and Quick Tunnel are not final deployment.
