# HydraCut Feature Observables

These are Build acceptance contracts. A feature passes only when the stated behavior is observed on the authentic stack; file existence or compilation alone is insufficient.

| Feature | Priority | Observable | Exact test command | Sentinel failure | Verified by |
|---|:---:|---|---|---|---|
| F-001 Frozen corpus import and provenance | P0 | Six immutable snapshots reproduce every stored commit and lockfile SHA from the frozen runtime evidence; a second seed creates no duplicate identity row. | `docker compose run --rm worker pnpm seed:demo && docker compose run --rm worker pnpm seed:demo` | Any hash mismatch, fabricated row, or duplicate snapshot | `corpus.integration` seed/provenance cases |
| F-002 Native baseline exposure | P0 | Native HydraDB `CALL algo.MSpaths` returns selected 3 pairs and bounded verification-universe 9 pairs, both equal independent BFS digests. | `docker compose --profile test run --rm test-runner pnpm test:corpus` | HydraDB unavailable yet a verified baseline is emitted; pair/cardinality/digest mismatch | HydraDB contract + corpus integration |
| F-003 Action-first incident command | P0 | `/incidents?role=appsec` opens with “What requires action now?”, the real minimist incident, freshness, and actionable result state. | `docker compose --profile test run --rm test-runner pnpm test:e2e --grep '^F01 '` | Empty/mock queue, generic dashboard, or verified copy from non-verified data | Playwright F01 + axe |
| F-004 Authentic proposed-fix evaluation | P0 | Three real later commits are immutable, fully extracted, rescanned, and classified removed/persistent/introduced/unknown. | `docker compose --profile test run --rm test-runner pnpm test:corpus --testNamePattern='proposed fix'` | Version-string inference, missing complete snapshot, or invented fix | Corpus proposed-fix cases |
| F-005 Coverage plan and final combined proof | P0 | The plan binds scopes, snapshots, source universe, and baseline digests; one fresh combined native traversal proves selected 3→0 while retaining other 9→6 evidence. | `docker compose run --rm worker pnpm proof` | Individual outcomes presented as final proof, stale plan accepted, or selected/remaining counts conflated | Proof runner + stale-plan mutations |
| F-006 Immutable receipt and SARIF | P0 | Canonical receipt digest recomputes; receipt and SARIF downloads retain state, bounds, source provenance, limitations, and receipt linkage. | `docker compose --profile test run --rm test-runner pnpm test:e2e --grep '^F07 '` | Digest mismatch, regenerated receipt, SARIF from partial state, or missing limitations | Playwright F07 + domain digest/SARIF tests |
| F-007 Fail-closed result states | P0 | Every Architecture §15.3 mutation removes verified language and ends `PARTIAL`, `UNKNOWN`, or `ERROR`; no new receipt is issued where forbidden. | `pnpm test && docker compose run --rm graph-contract && docker compose --profile test run --rm test-runner pnpm test:corpus` | Any false-clean result or receipt after a required evidence/proof failure | Domain, contract, corpus mutation matrix |
| F-008 Role-preserving projections | P1 | AppSec → Leader → Developer changes presentation only; incident, application, scope, plan, receipt, history, and focus context persist. | `docker compose --profile test run --rm test-runner pnpm test:e2e --grep '^F08 '` | Context reset, analysis rerun, or truth changes by role | Playwright F08 mobile/history case |
| F-009 Public exact-commit import | P1 | A public ref resolves to a 40-hex commit, fetched bytes match recorded hashes, Arborist executes no repository code, and a current portfolio snapshot is created. | `docker compose --profile test run --rm test-runner pnpm test:corpus --testNamePattern='exact commit'` | Mutable ref retained, subprocess/network mutation, absent portfolio membership, or partial tree accepted | Corpus GitHub/import cases |
| F-010 Public proposed-fix discovery | P1 | Paginated bot PR discovery persists repository, actor login/type, branch, head SHA, changed-file list/hash, and rate provenance before evaluation. | `docker compose --profile test run --rm test-runner pnpm test:corpus --testNamePattern='discovery'` | Human/unallowlisted actor accepted, pagination omitted, or evidence discarded | GitHub discovery contract cases |
| F-011 Portfolio and system views | P1 | Portfolio identities plus non-secret PostgreSQL/HydraDB readiness, graph image, limits, and operator boundary are visible without exposing secret values. | `docker compose --profile test run --rm test-runner pnpm test:e2e --grep '^F02 '` | Secret value rendered or a missing dependency reported healthy | Playwright F02 portfolio/system case |

All commands assume the exact Compose startup sequence in `hydracut/PLAN.md`. A sentinel failure blocks the feature regardless of other passing tests.
